# 第一章　量子状態と測定

## 1.0 この章で学ぶこと

量子力学という理論の骨組みは、突き詰めると次の三つの問いに対する答えでできています。

1. **状態** — 物理系の「いま」を、数学的にどう表すか
2. **測定** — その状態から、観測結果（と、その出る確率）をどう読み出すか
3. **時間発展** — 状態は時間とともにどう変化するか

古典力学なら答えは単純です。状態は「位置と速度の組」、測定は「その値をそのまま読むだけ」、時間発展は「ニュートンの運動方程式」。量子力学はこの三つをすべて置き換えます。本章ではこのうち **1（状態）と 2（測定）** を扱います。3（時間発展）は第三章の主題です。

出発点は数学ではなく、**一つの実験事実**です。1922年に行われたシュテルン＝ゲルラッハ実験は、古典的な世界観がどこで破綻するかを最も鮮明に見せてくれます。この実験を説明できる最小限の数学装置を組み立てていくと、自然に「状態ベクトル」「重ね合わせ」「ボルン則」「射影公準」という量子力学の中核概念に到達します。

> **前提知識について** — 本章で使う数学は、高校数学のベクトルと確率、それに複素数の基本演算だけです。複素数と2次元ベクトルの必要事項は 1.3 節でその場で導入します。

## 1.1 出発点の実験 — シュテルン＝ゲルラッハ

### 装置と基本の結果

シュテルン＝ゲルラッハ（Stern–Gerlach、以下 SG）実験の装置は、概念的には次のとおりです。

- 銀の原子を熱して蒸発させ、細いビームにして飛ばす
- ビームを、**強さが場所によって変わる（勾配のある）磁場** の中に通す
- 磁場を抜けた原子がスクリーンのどこに当たるかを記録する

銀原子は小さな磁石のように振る舞う性質（磁気モーメント）を持っており、勾配のある磁場の中では、その磁石の向きに応じた力を受けます。磁場の勾配方向を $`z`$ 軸としましょう。原子の磁石が $`z`$ 方向を向いていれば上向きの力、逆なら下向きの力、横向きならほぼ力を受けない — というのが古典的な予想です。

炉から飛び出してくる原子の磁石の向きはでたらめのはずなので、**古典的な予想はこうなります**：原子はスクリーン上で上から下まで連続的に帯状に分布する。

**実際の結果はこうでした**：原子は **上下の2点だけ** に当たる。中間は空白。

磁石の向きに相当する量（後に「スピン」と呼ばれる量の $`z`$ 成分）が、連続値ではなく **2つの離散値しか取らない** のです。これが「量子化」です。以下、上側に曲がった原子を「$`z+`$ の原子」、下側を「$`z-`$ の原子」と呼びます。

ここまでなら「原子の磁石は上向きか下向きの2種類しかないのだろう」と思えば済むかもしれません。本当に奇妙なのはここからです。

### 直列実験その1 — 再現性

SG 装置は $`z`$ 方向以外にも、装置ごと回転させれば任意の方向の測定ができます。$`x`$ 方向に勾配を向けた装置を SGx、$`z`$ 方向のものを SGz と書きます。

まず、SGz を2台直列に並べ、1台目で $`z+`$ に曲がった原子だけを選んで2台目の SGz に通します。

```
炉 → [SGz] → z+ のビームだけ選ぶ → [SGz] → 結果：100% が z+
```

全原子が再び $`z+`$ に曲がります。**同じ測定をすぐに繰り返すと、同じ結果が再現される。** これは安心できる性質で、そもそもこれが成り立たないなら「測定」という言葉に意味がありません。

### 直列実験その2 — 別方向の測定

次に、$`z+`$ に選別したビームを SGx に通します。

```
炉 → [SGz] → z+ を選ぶ → [SGx] → 結果：x+ が 50%、x− が 50%
```

$`z+`$ の原子たちは、$`x`$ 測定に対しては半々に分かれます。これ自体はまだ驚きではありません。「$`z`$ が上向きの原子は、$`x`$ 成分については半々に混ざっているのだろう」と考えれば説明できそうです。

### 直列実験その3 — 古典的世界観の破綻

問題はこの3段目です。直前の実験で $`x+`$ に曲がった原子だけを選び、もう一度 SGz に通します。

```
炉 → [SGz] → z+ を選ぶ → [SGx] → x+ を選ぶ → [SGz] → 結果：z+ が 50%、z− が 50%
```

**古典的な予想**：このビームの原子は、1段目で「$`z`$ は $`+`$」と確認済みで、2段目では $`x`$ を測っただけです。原子が $`z`$ の値と $`x`$ の値を両方「属性」として持っているなら、3段目では全原子が $`z+`$ に曲がるはずです。

**実際の結果**：半々に分かれます。1段目で確かめたはずの「$`z`$ は $`+`$」という情報が、**$`x`$ を測定したことによって消えてしまった** のです。

この実験事実が突きつけているのは次のことです。

> 原子は「$`z`$ 成分の値」と「$`x`$ 成分の値」を **同時に確定した属性として持つことができない**。測定とは、隠れていた値をそっと読み取る行為ではなく、**系の状態を変えてしまう行為** である。

この事実を矛盾なく記述できる数学の枠組みを、これから組み立てます。

> **コラム：なぜ銀原子か** — 銀原子は47個の電子を持ちますが、そのうち46個は対になって磁気的効果を打ち消し合い、最外殻の1個の電子のスピンだけが磁気モーメントとして残ります。つまり銀原子ビームの実験は、実質的に「電子スピン1個」の測定になっています。本章で扱う「2値しか取らない系」は量子力学で最も単純な系で、現代では **量子ビット（qubit）** と呼ばれる対象そのものです。

## 1.2 数学の準備 — 複素ベクトルと内積

SG 実験を記述するのに必要な数学を、必要な分だけ揃えます。線形代数を知っている読者は流し読みで構いません。

### 複素数

複素数は $`z = a + bi`$（$`a, b`$ は実数、$`i^2 = -1`$）と書ける数です。本章で使う道具は三つだけです。

- **複素共役**：$`z^* = a - bi`$（虚部の符号を反転する）
- **絶対値の2乗**：$`|z|^2 = z^* z = a^2 + b^2`$（必ず 0 以上の実数になる）
- **位相因子**：絶対値が 1 の複素数は $`e^{i\theta} = \cos\theta + i\sin\theta`$ と書ける

「絶対値の2乗が確率になる」というのが後で出てくるボルン則なので、$`|z|^2`$ の計算にだけは慣れておいてください。例えば

```math
\left| \frac{1+i}{2} \right|^2 = \frac{1-i}{2}\cdot\frac{1+i}{2} = \frac{1 - i^2}{4} = \frac{2}{4} = \frac{1}{2}.
```

### 2次元複素ベクトルとディラック記法

成分が複素数の2次元ベクトルを考え、量子力学の慣習に従って $`|\psi\rangle`$ という記号（**ケット**と読みます）で書きます。$`\psi`$（プサイ）は単なるラベルで、変数名のようなものです。

```math
|\psi\rangle = \begin{pmatrix} \alpha \\ \beta \end{pmatrix}, \qquad \alpha, \beta \in \mathbb{C}.
```

二つのベクトル $`|\phi\rangle = \begin{pmatrix} \gamma \\ \delta \end{pmatrix}`$ と $`|\psi\rangle = \begin{pmatrix} \alpha \\ \beta \end{pmatrix}`$ の **内積** を次で定義します。

```math
\langle \phi | \psi \rangle = \gamma^* \alpha + \delta^* \beta.
```

実ベクトルの内積との違いは、**左側のベクトルの成分に複素共役を付ける** ことだけです。こうしておくと、自分自身との内積

```math
\langle \psi | \psi \rangle = |\alpha|^2 + |\beta|^2
```

が必ず 0 以上の実数になり、「長さの2乗」として使えます。$`\langle \psi | \psi \rangle = 1`$ のとき、$`|\psi\rangle`$ は **規格化されている** といいます。

また、内積が 0 になる二つのベクトルは **直交する** といい、互いに直交する規格化ベクトルの組を **正規直交基底** と呼びます。2次元なら、正規直交基底は2本のベクトルの組です。もっとも基本的な例は

```math
|e_1\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \qquad |e_2\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}
```

で、任意のベクトルは $`|\psi\rangle = \alpha|e_1\rangle + \beta|e_2\rangle`$ と一意に展開できます。このとき係数は内積で取り出せます：$`\alpha = \langle e_1|\psi\rangle`$、$`\beta = \langle e_2|\psi\rangle`$。

> **記法メモ** — $`\langle\phi|`$ 単独（**ブラ**）は「左から内積を取る相手」を表す記号です。ブラ $`\langle\phi|`$ とケット $`|\psi\rangle`$ を合わせるとブラケット（bracket）$`\langle\phi|\psi\rangle`$、つまり内積になる、という語呂合わせがディラック記法の由来です。

## 1.3 公理1：状態は複素ベクトルである

道具が揃ったので、量子力学の最初の公理を置きます。

> **公理1（状態）** — 物理系の状態は、複素ベクトル空間の **規格化されたベクトル** $`|\psi\rangle`$（$`\langle\psi|\psi\rangle = 1`$）で表される。

SG 実験の銀原子（のスピン）の場合、測定結果が2値しかないことに対応して、状態空間は **2次元** です。$`z`$ 測定で確実に $`z+`$ に曲がる状態と確実に $`z-`$ に曲がる状態を、それぞれ

```math
|{+z}\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \qquad |{-z}\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}
```

と定めます。この2本は正規直交基底をなします（**$`z`$ 基底** と呼びます）。

### 重ね合わせ

公理1の本当の主張は「状態がベクトルである」こと、すなわち **足し算ができる** ことです。$`|{+z}\rangle`$ と $`|{-z}\rangle`$ が状態なら、その線形結合

```math
|\psi\rangle = \alpha\,|{+z}\rangle + \beta\,|{-z}\rangle, \qquad |\alpha|^2 + |\beta|^2 = 1
```

も正当な状態です。これを $`|{+z}\rangle`$ と $`|{-z}\rangle`$ の **重ね合わせ（superposition）** と呼びます。係数 $`\alpha, \beta`$ は **確率振幅**（または単に振幅）と呼ばれる複素数です。

とくに重要なのが次の二つの状態です。

```math
|{+x}\rangle = \frac{1}{\sqrt{2}}\bigl(|{+z}\rangle + |{-z}\rangle\bigr), \qquad
|{-x}\rangle = \frac{1}{\sqrt{2}}\bigl(|{+z}\rangle - |{-z}\rangle\bigr).
```

名前が示すとおり、これらが「$`x`$ 測定で確実に $`x+`$（$`x-`$）に曲がる状態」です。なぜこれでうまくいくのかは、次節のボルン則を置いた瞬間に検証できます。二つの違いが **係数の符号（相対位相）だけ** であることに注目しておいてください。

> **注意：重ね合わせは「どちらか分からない」ではない** — $`|{+x}\rangle`$ を「本当は $`+z`$ か $`-z`$ のどちらかなのだが、私たちが知らないだけの状態」と読みたくなりますが、それは誤りです。この違いは実験で区別できます（1.6 節で計算します）。重ね合わせは無知の表現ではなく、**どちらの値も確定していないという、古典力学に対応物のない状態** です。

## 1.4 公理2：ボルン則

状態から測定結果を読み出す規則が、量子力学の心臓部である **ボルン則（Born rule）** です。

> **公理2（ボルン則）** — 測定は、正規直交基底 $`\{|a_1\rangle, |a_2\rangle, \dots\}`$（各 $`|a_i\rangle`$ が測定結果 $`a_i`$ に対応する）で指定される。状態 $`|\psi\rangle`$ にあるとき、結果 $`a_i`$ が得られる確率は
>
> ```math
> P(a_i) = \bigl| \langle a_i | \psi \rangle \bigr|^2.
> ```

言葉にすると：**測りたい基底のベクトルと状態との内積（＝振幅）を取り、その絶対値の2乗が確率になる。** 量子力学が原理的に予言できるのはこの確率だけで、個々の測定でどちらが出るかを予言する方法は（現在知られている限り）存在しません。

### 確率の合計は1になるか

確率と呼ぶからには、全結果について足して 1 にならなければいけません。状態を測定基底で展開すると $`|\psi\rangle = \sum_i c_i |a_i\rangle`$（$`c_i = \langle a_i|\psi\rangle`$）であり、規格化条件から

```math
\sum_i P(a_i) = \sum_i |c_i|^2 = \langle\psi|\psi\rangle = 1.
```

公理1で状態に規格化を要求したのは、まさにこのためです。

### 検証：SG 実験の数値を再現する

**実験その2**（$`z+`$ のビームを $`x`$ 測定）を計算します。状態は $`|{+z}\rangle`$、測定基底は $`\{|{+x}\rangle, |{-x}\rangle\}`$ です。

```math
\langle {+x} | {+z} \rangle
= \frac{1}{\sqrt{2}}\bigl(\langle{+z}| + \langle{-z}|\bigr)\,|{+z}\rangle
= \frac{1}{\sqrt{2}}\bigl(\underbrace{\langle{+z}|{+z}\rangle}_{=1} + \underbrace{\langle{-z}|{+z}\rangle}_{=0}\bigr)
= \frac{1}{\sqrt{2}}.
```

よって

```math
P(x+) = \left|\frac{1}{\sqrt{2}}\right|^2 = \frac{1}{2}, \qquad P(x-) = \frac{1}{2}.
```

実験どおり **50% : 50%** です。$`|{\pm x}\rangle`$ の定義が正しく機能していることが確認できました。

> **コラム：なぜ「2乗」なのか** — マックス・ボルンが1926年にこの規則を提案したとき、論文の本文では「確率は振幅に比例する」と書き、校正段階の脚注で「より詳しい考察によれば確率は振幅の2乗に比例する」と訂正しました。量子力学の中心規則は脚注で生まれたのです。「なぜ2乗でなければならないか」は深い問いで、状態がベクトルで表されるという前提のもとでは2乗則以外に整合的な確率の与え方がないことを示す定理（グリーソンの定理、1957）が知られています。本書では公理として受け入れて先へ進みます。

## 1.5 公理3：射影公準 — 測定は状態を変える

残る実験事実は二つです。「同じ測定の繰り返しは同じ結果を与える」（実験その1）、そして「$`x`$ 測定は $`z`$ の情報を消す」（実験その3）。これを説明するのが第三の公理です。

> **公理3（射影公準）** — 測定で結果 $`a_i`$ が得られたら、測定直後の系の状態は $`|a_i\rangle`$ になる。

測定前の状態が何であったかによらず、測定後の状態は「得られた結果に対応する基底ベクトル」に置き換わります。状態が測定結果の方向へ**射影される**イメージから射影公準、あるいは劇的に「波束の収縮」とも呼ばれます。

### 検証：実験その1（再現性）

1台目の SGz で $`z+`$ が出た原子は、公理3により状態 $`|{+z}\rangle`$ になっています。2台目の SGz での確率は

```math
P(z+) = |\langle{+z}|{+z}\rangle|^2 = 1.
```

100% 再現。実験どおりです。

### 検証：実験その3（z 情報の消失）

3段の実験を最初から追跡します。

1. **1段目 SGz で $`z+`$ を選別** — 選別後の状態は $`|{+z}\rangle`$。
2. **2段目 SGx** — $`x+`$ が出る確率は 1.4 節の計算より $`1/2`$。$`x+`$ が出た原子の状態は、公理3により $`|{+x}\rangle`$ に**置き換わる**。もはや $`|{+z}\rangle`$ ではありません。
3. **3段目 SGz** — 状態 $`|{+x}\rangle = \tfrac{1}{\sqrt 2}(|{+z}\rangle + |{-z}\rangle)`$ に対する $`z`$ 測定なので、

```math
P(z+) = \left|\langle{+z}|{+x}\rangle\right|^2 = \frac{1}{2}, \qquad
P(z-) = \frac{1}{2}.
```

実験どおり **半々** です。謎めいて見えた「$`z`$ 情報の消失」は、この枠組みでは当然の帰結です。$`x`$ 測定した瞬間に状態が $`|{+x}\rangle`$ に更新され、$`|{+x}\rangle`$ は $`z`$ 基底から見れば半々の重ね合わせだからです。**測定が状態を書き換えるからこそ、二つの方向の値を同時に確定させておくことができない** — これが SG 実験の教訓の数学的な正体です。

> **注意：「収縮」の物理的実体について** — 射影公準は実験結果の計算規則としては完璧に機能しますが、「収縮とは物理的に何が起きているのか」「そもそも何をもって『測定』と呼ぶのか」には立ち入っていません。これは**測定問題**と呼ばれる現在も議論が続く問題で、第九章で扱います。当面は「使い方の規則」として受け入れて進みますが、この居心地の悪さは正当なものなので、覚えておいてください。

## 1.6 重ね合わせは「混ぜもの」ではない

1.3 節で予告した重要な区別を、道具が揃ったいま計算で示します。次の二つの原子集団を考えます。

- **集団A（重ね合わせ）**：全原子が状態 $`|{+x}\rangle = \tfrac{1}{\sqrt 2}(|{+z}\rangle + |{-z}\rangle)`$ にある。
- **集団B（統計的混合）**：半分の原子は $`|{+z}\rangle`$、残り半分は $`|{-z}\rangle`$ にある。どちらであるかを私たちが知らないだけ。

**$`z`$ 測定では区別できません。** 集団Aは ボルン則により $`z+`$ が確率 $`1/2`$。集団Bも、$`|{+z}\rangle`$ の原子は確実に $`z+`$、$`|{-z}\rangle`$ の原子は確実に $`z-`$ なので、全体では $`1/2`$。どちらも 50% : 50% です。

**しかし $`x`$ 測定では区別できます。**

- 集団A：状態が $`|{+x}\rangle`$ そのものなので、$`P(x+) = |\langle{+x}|{+x}\rangle|^2 = 1`$。**100% が $`x+`$。**
- 集団B：$`|{+z}\rangle`$ の原子も $`|{-z}\rangle`$ の原子も、$`x`$ 測定では半々に分かれる（1.4 節と同様の計算）。**全体で 50% : 50%。**

つまり「重ね合わせ」と「どちらか分からないだけの混合」は、**測る向きを変えれば実験的に区別できる、物理的に異なる状況** です。重ね合わせを無知の表現と解釈する読み方は、ここで実験と矛盾して否定されます。

### 相対位相は物理的である

同じ計算からもう一つの教訓が得られます。$`|{+x}\rangle`$ と $`|{-x}\rangle`$ の違いは係数の符号、つまり **相対位相** だけでした。$`z`$ 測定ではどちらも 50% : 50% で区別できませんが、$`x`$ 測定では前者が 100% $`x+`$、後者が 100% $`x-`$ と、完全に区別されます。**振幅の位相は、確率の「2乗」で消えてしまいそうに見えて、消えない。** 別の基底で測ると顔を出すのです。位相こそが量子力学を単なる確率論と分かつものであり、第二章（干渉）の主役になります。

なお、状態全体に共通の位相を掛けたもの（例えば $`|\psi\rangle`$ と $`e^{i\theta}|\psi\rangle`$）は、あらゆる測定確率が一致するため、**同じ物理状態** とみなします（各自確かめてみてください。演習4）。物理的なのは相対位相だけです。

## 1.7 まとめ

本章で導入した量子力学の骨組み（時間発展を除く）は、次の3公理です。

1. **状態**：系の状態は規格化された複素ベクトル $`|\psi\rangle`$。ベクトルなので重ね合わせができる。
2. **ボルン則**：基底 $`\{|a_i\rangle\}`$ の測定で結果 $`a_i`$ が出る確率は $`P(a_i) = |\langle a_i|\psi\rangle|^2`$。
3. **射影公準**：結果 $`a_i`$ が出たら、直後の状態は $`|a_i\rangle`$ に更新される。

この3行だけで、シュテルン＝ゲルラッハの直列実験のすべての数値（100%、50/50、50/50）が再現されました。また次の概念的教訓を得ました。

- 測定は「隠れた値の読み取り」ではなく「状態の書き換え」である
- 重ね合わせは無知ではなく、測る基底を変えれば混合と実験的に区別できる
- 全体位相は無意味だが、相対位相は物理的である

**次章予告**：相対位相が最も劇的に現れる現象が **干渉** です。第二章ではマッハ・ツェンダー干渉計を舞台に、「粒子は二つの経路を同時に通るのか？」という問いに3公理がどう答えるかを見ます。

## 演習問題

**演習1（規格化とボルン則）** 状態 $`|\psi\rangle = \tfrac{1}{\sqrt{5}}\bigl(|{+z}\rangle + 2\,|{-z}\rangle\bigr)`$ について、(a) 規格化されていることを確かめよ。(b) $`z`$ 測定で $`z+`$、$`z-`$ が出る確率をそれぞれ求めよ。

<details>
<summary>解答</summary>

(a) $`\langle\psi|\psi\rangle = \left|\tfrac{1}{\sqrt 5}\right|^2 + \left|\tfrac{2}{\sqrt 5}\right|^2 = \tfrac{1}{5} + \tfrac{4}{5} = 1`$。

(b) $`P(z+) = \left|\tfrac{1}{\sqrt 5}\right|^2 = \tfrac{1}{5}`$、$`P(z-) = \tfrac{4}{5}`$。

</details>

**演習2（直列 SG の確率）** $`z+`$ に選別された原子が、SGx を通って $`x-`$ に曲がり、さらに SGz を通って $`z-`$ に曲がる確率を求めよ。

<details>
<summary>解答</summary>

各段の確率をボルン則で計算し、射影公準で状態を更新しながら掛け合わせる。
$`P = |\langle{-x}|{+z}\rangle|^2 \times |\langle{-z}|{-x}\rangle|^2 = \tfrac{1}{2} \times \tfrac{1}{2} = \tfrac{1}{4}`$。

</details>

**演習3（複素振幅）** 状態 $`|\psi\rangle = \tfrac{1}{\sqrt 2}\bigl(|{+z}\rangle + i\,|{-z}\rangle\bigr)`$ について、(a) $`z`$ 測定の各確率を求めよ。(b) $`x`$ 測定の各確率を求めよ。（この状態は実は「$`y`$ 方向」のスピン状態です。2次元の複素ベクトルで3次元の全方向が表せる仕組みは第八章で扱います。）

<details>
<summary>解答</summary>

(a) $`P(z+) = \left|\tfrac{1}{\sqrt 2}\right|^2 = \tfrac 12`$、$`P(z-) = \left|\tfrac{i}{\sqrt 2}\right|^2 = \tfrac 12`$。

(b) $`\langle{+x}|\psi\rangle = \tfrac{1}{\sqrt 2}\cdot\tfrac{1}{\sqrt 2}(1 + i) = \tfrac{1+i}{2}`$ なので $`P(x+) = \left|\tfrac{1+i}{2}\right|^2 = \tfrac 12`$。同様に $`P(x-) = \tfrac 12`$。$`z`$ でも $`x`$ でも半々になる状態が存在する、という点がミソ。

</details>

**演習4（全体位相の無意味さ）** 任意の状態 $`|\psi\rangle`$ と、それに位相を掛けた $`|\psi'\rangle = e^{i\theta}|\psi\rangle`$ は、任意の測定基底 $`\{|a_i\rangle\}`$ に対して同じ確率分布を与えることを示せ。

<details>
<summary>解答</summary>

$`P'(a_i) = |\langle a_i|\psi'\rangle|^2 = |e^{i\theta}\langle a_i|\psi\rangle|^2 = |e^{i\theta}|^2\,|\langle a_i|\psi\rangle|^2 = 1 \cdot P(a_i)`$。絶対値1の因子は2乗で消えるため、すべての測定で区別できない。

</details>

**演習5（概念問題）** 「SG 実験の原子は、実は各方向のスピン値をあらかじめ全部持っているが、測定装置がビームを乱すせいで値が変わってしまうだけだ」という反論を考える。この立場（隠れた変数理論の素朴版）は本章の実験事実だけで否定できるか、考察せよ。

<details>
<summary>解答</summary>

本章の実験だけでは否定できない。「測定が値を乱す」という筋書きで直列 SG の結果を再現する古典モデルは実際に作れる。素朴な隠れた変数理論が実験的に否定されるのは、複数粒子のもつれを使ったベルの不等式の破れ（第五章）による。本章の3公理は「実験を最も簡潔に記述する枠組み」であって、この段階では唯一の可能性ではない — と正直に認識しておくのが健全である。

</details>

## 用語集

- **状態ベクトル** — 系の状態を表す規格化された複素ベクトル $`|\psi\rangle`$。
- **ケット / ブラ** — ベクトルを表す記号 $`|\psi\rangle`$ と、左から内積を取る相手 $`\langle\phi|`$。合わせて内積 $`\langle\phi|\psi\rangle`$。
- **基底（正規直交基底）** — 互いに直交する規格化ベクトルの組。測定は基底の指定に対応する。
- **重ね合わせ** — 状態の線形結合。無知の表現ではなく、固有の物理状態。
- **確率振幅** — 展開係数 $`\langle a_i|\psi\rangle`$。複素数で、絶対値の2乗が確率。
- **ボルン則** — $`P(a_i) = |\langle a_i|\psi\rangle|^2`$。状態と確率をつなぐ規則。
- **射影公準（波束の収縮）** — 測定後、状態は得られた結果の基底ベクトルに更新される。
- **規格化** — $`\langle\psi|\psi\rangle = 1`$ とすること。確率の合計を1にするための条件。
- **相対位相 / 全体位相** — 振幅どうしの位相差は物理的（測定で区別可能）。状態全体に掛かる位相は無意味。
- **量子ビット（qubit）** — 2次元の状態空間を持つ系。本章のスピンはその実例。
