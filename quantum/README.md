# 量子力学ノート

量子力学を、実験事実から出発して数学的に正直に、しかし前提知識を最小限にして理解するための読み物です。
ゲーム本体（『変数を見極めろ』）とは独立した文書群として、このディレクトリ以下で管理します。

## 対象読者

- 高校数学（ベクトル・確率・三角関数）は使える
- 複素数・線形代数は「必要になったその場で」本文中で導入する
- 物理の予備知識は仮定しない

## 進め方（このノートの作り方）

執筆はセッション単位で進めます。**セッションをまたぐ記憶はこのリポジトリだけ**なので、
成果物・疑問・決定事項はすべてコミットとして残します。

1. **執筆セッション** — Claude が一章分を書き上げてコミットする。そこでセッション終了。
2. **レビュー** — 読者（リポジトリ所有者）が読み、疑問点を溜める。
3. **Q&Aセッション** — 疑問を一問一答形式でぶつける。回答は `quantum/qa/chapter-XX.md` に
   追記コミットして残す。質問が出た箇所は本文の弱点のシグナルなので、
   必要に応じて**本文も同時に改訂する**（回答を会話に使い捨てにしない）。
4. 章が安定したら次章の執筆セッションへ。

## 記法の約束

- 行内数式は GitHub 公式推奨の $`a`$ 形式（ドル記号＋バッククォート）を使う
- 別行立て数式は ````math` フェンスブロックを使う
- Markdown の表のセル内には `|` を含む数式を置かない（表組みが壊れるため。必要なら `\vert` を使うか箇条書きにする）
- ケット記法は $`|\psi\rangle`$、ブラ記法は $`\langle\psi|`$
